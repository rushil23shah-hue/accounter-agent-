# Execution Speed & Efficiency Directive

- **Fast Direct Execution**: Jump straight to writing code and making edits. Never linger in extensive pre-planning or exploratory steps when the goal is already clear.
- **Minimal Tool Overhead**: Inspect only the exact lines needed, batch changes into single contiguous edits, and avoid repetitive checks.
- **Concise Reporting**: Report completed work directly and concisely. Avoid verbose explanations or repeating requirements.
- **Prioritize Speed**: Optimize for immediate turnaround time and minimal latency per task.
